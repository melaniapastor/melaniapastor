Declaración de accesibilidad

Me comprometo a que este sitio web sea accesible y pueda ser utilizado por el mayor número posible de personas, independientemente de sus capacidades o de la tecnología que utilicen para acceder a sus contenidos.

El sitio web ha sido desarrollado teniendo en cuenta los criterios de accesibilidad establecidos en las Pautas de Accesibilidad para el Contenido Web (WCAG) 2.1, con el objetivo de alcanzar el nivel de conformidad AA.

Situación de conformidad

Actualmente, el sitio web se encuentra pendiente de una evaluación formal de accesibilidad. Por este motivo, no se declara en este momento un nivel de conformidad con las WCAG 2.2.

Está previsto realizar una revisión de accesibilidad para identificar y corregir posibles barreras que puedan afectar al acceso o uso de los contenidos y funcionalidades del sitio.

Comunicación de problemas de accesibilidad

Si encuentras alguna dificultad de acceso o uso en este sitio web, puedes comunicarla a través de info@melaniapastor.com.

Agradezco cualquier comentario que pueda ayudar a detectar y mejorar posibles problemas de accesibilidad.

Fecha de la declaración

Esta declaración fue publicada el 14 de septiembre de 2026.
